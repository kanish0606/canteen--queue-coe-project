# 🍴 Smart Canteen Queue

## Project Better Tomorrow

Smart Canteen Queue is a simple web-based prototype designed to help college students check the current canteen crowd and join the queue digitally.

## 📌 Problem Statement

Students waste valuable break time waiting in long queues at the college canteen because they cannot know the current crowd or estimated waiting time before reaching the counter.

## 💡 Solution

The Smart Canteen Queue system allows students to:

- 👥 View the number of people currently in the queue
- ⏱️ See the estimated waiting time
- 🟢 Check the crowd status
- 🎫 Join the queue digitally
- 📍 View their position in the queue
- 👨‍🍳 Allow staff to serve the next student
- 🔄 Reset the queue

## 🛠️ Technologies Used
